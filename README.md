# A股短线量化工作站

一个可直接运行的个人短线量化网站：市场雷达、八套短线策略、个股 K 线详情、回测中心、条件筛选与自选模拟盘。当前环境不需要 Node.js 或 npm，Python + Flask + 原生前端即可启动。

## 快速启动

```powershell
python app.py
```

浏览器打开 http://127.0.0.1:5000 。

如需修改端口：

```powershell
python app.py --port 8765
```

联网环境可切换腾讯/东财真实行情快照与真实 K 线：

```powershell
python app.py --port 8765 --live
```

`--live` 模式优先使用腾讯免费行情（与同花顺等常用行情价格一致），腾讯缺失时自动回退东财；行情源临时不可用时保留最后一次可用快照。`run.bat` 已默认以真实行情模式启动。

## 部署成公网网站

GitHub Pages 只能托管静态文件，不能运行本项目的 Flask 后端，因此要让别人直接访问完整实时行情，需要把后端部署到公网服务。

推荐路线：GitHub 仓库 + Render。

1. 在 GitHub 新建仓库并把本目录推上去。
2. 在 render.com 用 GitHub 账号登录。
3. 新建 Web Service 并选择该仓库，Render 会自动读取仓库内的 `render.yaml`。
4. 等待构建完成后，Render 会给出公网 URL。

也可使用 Railway 或 Docker，仓库已包含 `render.yaml`、`railway.json`、`Dockerfile` 和 `Procfile`。

临时方案：本机保持开机时，可用 `cloudflared tunnel --url http://127.0.0.1:8765` 生成临时公网地址，但它仍依赖本机。

当前离线样本池包含 331 只 A 股，其中 312 只沪深主板股票，覆盖成交活跃的银行、白酒、半导体、医药、新能源、汽车、资源等板块。

## 页面与功能

- 市场雷达：全池涨跌家数、涨停、当前信号、强中弱、高合格差分布与实时信号表。
- 股票筛选：股价区间、涨跌幅、量比、换手、行业、板块、信号强度与信号质量组合过滤，结果数量实时显示。
- 策略工作台：竞价弱转强、强势回踩低吸、平台放量突破、尾盘强势潜伏、强势股首阴反包，每套策略展示规则、时间窗口和独立历史胜率。
- 个股详情：日 K / 1-60 分钟 K、MA/BOLL/MACD/KDJ/RSI/ATR、实时指标、当前信号、八套策略各自胜率。
- 回测中心：模拟 T+1、涨跌停、交易成本，输出交易笔数、胜率、盈亏比、累计/年化收益、最大回撤、夏普与资金曲线。
- 自选与模拟盘：自选行情、模拟买入/卖出、持仓与委托记录。

## 八套策略

| 策略 | 窗口 | 买卖要点 |
| --- | --- | --- |
| S1 竞价弱转强 | 09:15-09:35 | 昨日缩量阴线不破趋势，竞价由弱转强，T+1 止盈止损 |
| S2 强势回踩低吸 | 09:45-10:30 | MA5/10/20 多头，回踩 MA5 放量收回 |
| S3 平台放量突破 | 10:00-14:00 | 20 日窄平台放量突破前高，拒绝涨停追单 |
| S4 尾盘强势潜伏 | 14:25-14:57 | 尾盘维持强度、高于 VWAP，博次日高开 |
| S5 强势股首阴反包 | 13:30-14:30 | 龙头缩量首阴后分时站回昨收 |
| S6 多头趋势回踩 | 10:00-14:30 | MA20/MA60 多头，缩量回踩 MA10 后确认 |
| S7 均线粘合突破 | 10:00-14:00 | 均线粘合后放量突破 10 日平台 |
| S8 缩量回调反包 | 09:45-14:30 | 缩量阴线后低开翻红，快进快出 |

所有规则默认按 A股 T+1、涨跌停与免费行情源约束实现；回测统计为事件驱动的日线近似口径，按单仓 10%、最多 5 仓执行。

## 文件说明

- `app.py`：Flask API、实时推流、模拟盘与 live 模式入口。
- `market.py`：股票池、日线/分钟 K 生成、技术指标快照与离线行情推演。
- `strategies.py`：八套策略规则与信号强度/质量分级。
- `backtest.py`：统一回测、资金曲线与胜率等指标。
- `live_source.py`：腾讯/东方财富免费行情适配（实时快照与 K 线）。
- `data/mainboard_stocks.json`：由东方财富抓取并固化的主板股票池。
- `render.yaml` / `railway.json` / `Dockerfile` / `Procfile`：公网部署配置。
- `static/`：无构建前端，含原生 Canvas K 线图表。

## 自动化测试

```powershell
python -m pytest -q
```

测试覆盖行情生成、分钟 K、信号标签以及八套策略回测报告完整性。

## 数据与风险

默认运行在确定性离线演示数据上，便于随时打开体验；`--live` 仅把现有样本池的实时快照与单股 K 线切换为东财免费源。免费源为分钟级准实时，非券商 Level-1/Level-2 推送。本项目只做研究、监控与模拟盘，不构成投资建议，所有历史胜率都随策略参数与回测口径变化。
